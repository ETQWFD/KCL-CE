KCL2

保留原版下载、正版登录、版本隔离和 Mod 加载工作流，在启动器不可用时提供一个备选入口。

能下载，也能启动KCL2 可直接下载并启动 Minecraft 版本，沿用 Mojang 官方源与 BMCLAPI 镜像，支持正版登录、版本隔离与 Mod。游戏版权归 Mojang/Microsoft，KCL2 不销售游戏、不收充值、不运营服务器。

版本下载

支持官方清单、镜像源、Forge、NeoForge、Fabric、OptiFine 与整合包安装流程。

正版登录

支持微软账号设备码授权。首次使用需配置属于 KCL2 的 Azure 公共客户端 ID。

本地数据

程序目录使用 kcl 文件夹保存日志、图片、音乐和自定义主页。

公平启动

启动前检查已知作弊客户端、作弊 Mod 和未授权 Java 注入参数，命中后停止启动并写出拦截记录。

为什么需要备选启动器

当所有常见启动器暂时不可用时，游戏不应该因此停止。KCL2 负责下载、安装、启动和管理本地 Minecraft 版本，不销售游戏、不收取充值费用，也不运营多人服务器。未成年人充值、服务器封禁、道具和退款问题，请联系服主、支付渠道或 Microsoft/Mojang 官方支持。

开始使用

  1. 从 Release 下载压缩包。
  2. 解压到非临时目录后运行 KCL2.exe。
  3. 首次启动阅读并同意第三方修改与免责声明。
  4. 在下载页选择 Minecraft 版本，或在账户页使用微软登录。
