# KCL CE

KCL CE 是基于 **PCL 社区版（Plain Craft Launcher Community Edition，PCL-Community/PCL-CE）** 的独立第三方修改版，由 **龙腾OS（ETC Team）** 修改与维护。

- 产品名称：KCL CE
- 修改维护：龙腾OS / ETC Team
- 上游社区版：[PCL-Community/PCL-CE](https://github.com/PCL-Community/PCL-CE)
- 原作名称：Plain Craft Launcher / PCL，原作者龙腾猫跃（LTCat）
- 当前仓库：https://github.com/ETQWFD/KCL-CE
- 下载与官网：https://etqwfd.github.io/KCL2/

## 与上游的差异

- 品牌名、程序名与图标改为 KCL CE；启动器自身目录使用 KCL。
- 不按地区封锁功能：所有地区都可使用版本下载、社区资源（CurseForge/Modrinth）、整合包与联机入口。
- 内置 CurseForge API Key：无需用户自行申请即可搜索、下载模组与整合包。
- 检查更新只检查本仓库（ETQWFD/KCL-CE）发布，不连接上游社区版更新服务器。
- 关于页保留 PCL Community 与龙腾猫跃的署名，并标明本版与原作者无关联。

## 为什么会有 KCL CE

当常见启动器因网络、维护或外部压力暂时不可用时，玩家仍需要一个能进入本地游戏的备选入口。KCL CE 在这种情况下延续版本下载、正版登录与本地实例管理能力。

KCL CE 不运营 Minecraft，也不运营任何多人服务器。未成年人充值、服务器封禁、道具纠纷、支付退款或服务器管理规则，请联系对应服主、服务器管理组、支付渠道或 Microsoft/Mojang 官方支持。
